# 온리프 · Onleaf

EPUB과 TXT를 편안하게 읽는 개인 전자책 서재 초안입니다. React + TypeScript + Vite로 만들었으며 서버나 회원가입 없이 현재 브라우저에 책과 읽기 기록을 저장합니다.

## 실행

Node.js 22.12 이상(또는 호환되는 최신 LTS)이 필요합니다.

```powershell
cd D:\programm\e-book
npm.cmd install
npm.cmd run dev
```

브라우저에서 http://127.0.0.1:5173 에 접속하세요. Windows에서는 `온리프 실행.cmd`를 더블클릭해도 됩니다. 같은 주소와 브라우저를 사용해야 기존 서재가 보입니다. 종료하려면 실행한 터미널에서 Ctrl+C를 누르세요.

```powershell
npm.cmd run build   # 타입 검사 + 배포용 dist 생성
npm.cmd test        # 파일 파싱, 페이지 분할, 저장 기능 테스트
npm.cmd run preview # 빌드 결과 확인 (개발 서버와 주소/포트가 다르면 별도 서재)
```

## 사용 방법

- **책 추가하기**: EPUB·TXT를 선택하거나 서재 화면으로 여러 파일을 끌어다 놓습니다. 파일당 30MB까지 지원합니다. 동일한 파일은 SHA-256으로 식별해 중복 추가하지 않습니다.
- **독서**: 표지 또는 제목을 누릅니다. 읽던 페이지가 자동 저장되고 좌우 방향키나 버튼, 하단 슬라이더로 이동할 수 있습니다. 페이지가 화면보다 길면 아래로 스크롤하세요.
- **목차·책갈피**: 읽기 화면 상단에서 장을 선택하거나 현재 페이지에 책갈피를 추가합니다. 서재의 책갈피 메뉴에서도 바로 돌아갈 수 있습니다.
- **읽기 설정**: 밝게·따뜻하게·어둡게, 명조·고딕, 글자 크기 14–28px를 지원합니다. 설정도 저장됩니다.
- **완독**: 마지막 페이지에서 ‘다 읽었어요’를 누르면 완독한 책에 담깁니다.
- **서재 관리**: 제목·저자 검색, 파일 형식 필터, 최근 읽은 순·추가한 순·제목 순 정렬, 격자·목록 보기, 삭제를 지원합니다. 삭제 시 확인 창이 표시됩니다.

처음에는 직접 작성한 짧은 샘플 글 6권이 제공됩니다. 실제 출판 도서를 재현한 콘텐츠가 아닙니다. 샘플을 삭제해도 다음 실행 때 다시 추가되지 않습니다.

## 초안의 범위

- **텍스트 중심 리더**입니다. EPUB의 메타데이터·표지·본문 읽기 순서(spine)를 사용하고, 본문은 안전한 일반 텍스트로 표시합니다. 장 제목으로 목차를 구성합니다.
- EPUB 원본 서식, 본문 이미지·표·주석 링크, 세로쓰기, 고정 레이아웃, PDF, DRM은 지원하지 않습니다. EPUB 압축 해제 총량은 80MB, 개별 항목은 12MB로 제한합니다.
- TXT는 UTF-8, BOM이 있는 UTF-16, 일반적인 한국어 EUC-KR/CP949 파일을 읽습니다.
- 페이지는 텍스트 기준으로 나누므로 글자 크기를 바꾸어도 같은 위치를 유지합니다. 큰 글꼴이나 작은 화면에서는 한 페이지를 스크롤할 수 있습니다.
- 데이터는 현재 브라우저의 **IndexedDB**에, 읽기 설정은 **localStorage**에 저장합니다. 외부 서버로 책을 전송하지 않습니다. 계정·클라우드 동기화·백업 기능은 아직 없습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 주소·브라우저로 접속 시 기존 서재를 사용할 수 없을 수 있습니다. 원본 파일은 별도로 보관하세요.
- 초기 패키지 설치에는 인터넷이 필요합니다. 실행 중 앱은 외부 API·폰트·이미지 서비스에 의존하지 않습니다.

## 코드 구성

- `src/App.tsx`: 서재, 검색·정렬·필터, 가져오기, 책갈피 모음
- `src/components/Reader.tsx`: 독서 화면, 목차, 읽기 설정, 페이지 이동
- `src/lib/import-book.ts`: EPUB·TXT 파싱 및 파일 검증
- `src/lib/storage.ts`: IndexedDB 저장
- `src/lib/books.ts`: 페이지 분할, 독서 진행률, 설정
- `src/lib/samples.ts`: 직접 작성한 샘플 콘텐츠
- `src/styles.css`: 서재·독서 화면 및 반응형 스타일

EPUB 압축 해제는 [fflate 공식 문서](https://github.com/101arrowz/fflate)를 참고했습니다. 개발 서버와 빌드는 [Vite](https://vite.dev/guide/)를 사용합니다.
